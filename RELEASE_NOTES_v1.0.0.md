# ExpenseMargin v1.0.0 — Public Launch

This release completes the build train from the production MVP through the customer-ready launch surface.

## Included
- Public signup and email-confirmation callback
- Password recovery and password update flow
- Secure sign-out
- Public pricing, security, privacy, and terms pages
- Production SEO metadata, robots policy, and sitemap
- Launch checklist for Supabase Auth, Stripe, Resend, Vercel, and consolidated QA
- App/package version promoted to 1.0.0

## Validation policy
The code is merged only after project checks, TypeScript validation, and a production Next.js build pass in GitHub Actions. Full product end-to-end QA remains intentionally deferred until the complete build train is merged, per the development plan.
